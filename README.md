## Creative programme
Three streams are maintained together: **Story**, **CYOD architecture**, and **World Bible**. Book One's three-act structure and minimalist wrist-choice opening are approved as *design architecture*. Actual manuscript chapters, final illustrations, exact world-laws, protagonist identity, and the solution to ZETA's larger mystery are not yet approved.

W001–W003 creative architecture is frozen at exact scope. W004 adopted an **iterative vertical-slice writing workflow** and a **simplified scene-based visual editor**. Start at the three-Act overview, open a scene, click a passage and write. W005 is installed for **durable manuscript storage and recovery**, but has not run.

**Manuscript data warning:** The current Studio uses browser-local `localStorage`, *not* cloud persistence. Export JSON backups from the editor's **•••** menu until a verified server-side save and restore system exists. The linked Vercel project is `zeta-writing-studio` with root `studio/`; deployment is a separate owner action.

The accepted Book One narrative is wrongful mathematically motivated exile → regional investigation/refutation → return and vindication with unresolved agency foreshadowing. Navigation blends River (Act I), Atlas (Act II), Living Book (Act III), authored page/paragraph navigation, guided discovery and choice-led danger rather than combat RPG. Reader-facing text does not explicitly name maths/mathematics. Do not promote proposals to canon without explicit owner approval. This repository is an internal creative archive, not a published novel.
