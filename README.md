# ZETA — Universe archive and *Leave the Citadel*

**Status:** S000 infrastructure prepared; W001 not started. **Working title:** *Leave the Citadel* (not final).

ZETA is a developing, mathematically inspired fictional universe combining fantasy, science fiction, AI, philosophy, exploration and interactive storytelling. The first planned creative work is a Choose Your Own Destiny (CYOD) novel. This repository is the authoritative **working archive**, not a published world bible or a completed novel.

## Working method

Workshops are collaborative discussions, not automatic content generation. Every substantial fictional claim bears a status: **CANON**, **PROVISIONAL**, **PROPOSAL**, **OPEN** or **REJECTED**. An assistant's suggestion is never approved by implication. See [AGENTS.md](AGENTS.md) for AI-assisted session rules.
